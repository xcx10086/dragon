# 《龙之谷》版本介绍页 · 还原度对照说明（二期）

> 需求：飞书项目 story `7160565911`《龙之谷》新版本介绍页（背景套用官网 web12 KV，资料片视频改为新版本信息，内容搬运 2026Asc 活动页）
> 一期需求：story `7160662756`《龙之谷》活动介绍页（仿官网 web12 美术效果）
> 技术方案：《龙之谷》2026 夏季版本介绍页技术方案（docx `S2fFda9aUo1msHxAOFicS9Ctn9d`）
> 基线：`xcx10086/mianshuang` · `main` · `69d600fc9654baeae4f7ea6e08f0908830c37c5e`
> 开发分支：`feature/dn-2026-summer-version`

本期在一期已验收的单文件页上迭代，**三条结构性变化**如下：

1. **KV 改为直引官网同图**：一期三层自绘渐变（`.kv-1/.kv-2/.kv-3`）与轮播整体下线，替换为单张 `<img class="kv-img">` 直引 `static.web.sdo.com/dn/pic/dn/web12/20261029/bg.jpg`，页面由此不再「零外链」。
2. **资料片视频整链路下线**：`#heroPlay`/`#expPlay`、`#videoModal`、`.btn-play`/`.video-pop` 样式、视频弹窗 JS 模块、`CONFIG.VIDEO_SRC` 与 `assets/kv-trailer.mp4` 全部删除，原位置由 `#version` 新版本信息版块承接。
3. **内容以 2026Asc 线上页为准整体搬运**：新职业、征名活动、预约活动三区按原站模块/文案/素材落位，演示态交互（六步征名弹窗、预约进度条、绑定与注销）本地实现。

## 4. 实现要点

- 页面结构：导航 / 主视觉 KV / 新版本信息 / 活动入口+倒计时 / 新职业 / 征名活动 / 预约活动 / 关联入口 / 页脚，九版块与方案 3.2 表格一致。
- 交互：导航滚动态、reveal 淡入、征名六步状态机（校验 → 确认 → 成功 → 手机号与验证码 → 企微码 → 完成）、预约进度与里程碑、绑定/注销、`toast` 演示反馈、外链新窗口。
- 状态持久化：`dn_bgm`（音乐）、`dn_name_submit`（征名名称，模拟不可更改）、`dn_reserved`（预约状态）；全部 localStorage，不发起网络请求。
- 性能：首屏关键路径为 HTML + 一张官网 KV（preload + high 优先级），其余图片懒加载并预留 `aspect-ratio`；样式与脚本全内联，无构建。
- 自适应：1100px（活动卡两列、版本卡单列）、980px（导航折叠、信息块单列）、820px（里程碑单列、悬浮入口收窄）、560px（活动卡单列、新职业图组横向滑动 `scroll-snap`、KV 焦点切 `62% 38%`、按钮全宽）。
- 无障碍与降级：弹窗 `role="dialog"` + `aria-modal` + ESC/遮罩关闭 + 关闭后焦点回收；验证码倒计时按钮置灰不可重复点；预约按钮 `aria-pressed`；进度条 `role="progressbar"` + `aria-valuenow`；`prefers-reduced-motion` 关闭动效；KV/图组/进度条底图/二维码均有失败降级。
