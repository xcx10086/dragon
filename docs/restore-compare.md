## 4. 实现要点（与方案 3.2–3.6 的对应）

- 页面结构：导航 / 主视觉 / 活动入口+倒计时 / 资料片+福利 / 视频弹窗 / 页脚，六版块与方案表格一致。
- 交互：导航滚动态、reveal 淡入、KV 轮播（5s 自动 + hover 暂停 + 触摸滑动 + 圆点切换）、倒计时（单定时器、结束态、无负数）、音乐开关（交互解锁 + localStorage）、视频弹窗（注入/释放 src、ESC/遮罩关闭、错误兜底）。
- 性能：零外链、CSS/JS 全内联，首屏请求数 1；CSS 与 JS 体积约 54 KB（未压缩）。
- 自适应：980px（导航折叠、图文单列）、820px（悬浮入口收窄）、560px（活动卡单列、倒计时缩放、按钮全宽）。
- 无障碍与降级：按钮均带 `aria-label`/`aria-pressed`，弹窗 `role="dialog"` + `aria-modal`，`prefers-reduced-motion` 下关闭动效，`backdrop-filter` 不支持时回退纯色底。
