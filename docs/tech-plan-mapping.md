## 4. KV 三档裁切结论（`object-fit:cover` + 焦点定位）

| 视口 | `object-position` | 目视结论 |
|-|-|-|
| 1920×1080 | `50% 42%` | 左上 BOSS、左下持盾权杖角色、中左刺客、右上弓箭手、右近景女战士与粉色宠物全部在画；红底飘带文案完整，无留白、无拉伸 |
| 1440×900 | `50% 42%` | 横向裁切约 25%，主体仍在安全区内；上缘光源与下缘暖红过渡保留 |
| 375×812（竖屏） | `62% 38%` | 竖屏按 50% 居中会切掉左右两端角色与女战士，故焦点右移并上提；保 BOSS 与右侧女战士，中左刺客允许被裁 |

裁切规则写入 CSS 媒体查询（`@media(max-width:560px)` 单独改 `object-position`），不依赖 CSS `background-position` 的百分比换算差异。

## 5. 演示态边界

- 代码内不存在真实提交、短信、登录、绑定接口调用：无 `fetch` / `XMLHttpRequest` 调用点，仅 `localStorage` 保存演示状态（`dn_bgm` / `dn_name_submit` / `dn_reserved`）。
- 征名提交后将名称落 `localStorage.dn_name_submit`，再次打开弹窗直接进入 pop3，模拟「确认后不可更改」。
- 预约人数基线 `CONFIG.RESERVE.count = 128000`，预约后 +1，注销后回落；里程碑阈值 5 万 / 10 万 / 15 万按总人数判定。
- 页脚与各活动块均标注演示性质；页脚关于文案写明「活动时间、人数、奖励与实际活动可能存在差异，页面内提交与验证为界面演示」。
